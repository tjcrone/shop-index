# Shop Fastener Index

Index of the shop's fastener bins, by material and fastener type.

A size range bounds what a run of bins covers; it does not promise every size in between.

Transcribed from four handwritten sheets — see [NOTES.md](NOTES.md) for the source photos and transcription details.

| --- | --- | --- |

| Socket Head Cap Screws | 1/4-28 × 2 → 3/4-10 × 6 | 3000–3037 |
| Hex Head Cap Screws | 1/4-20 × 3/8 → 1"-8 × 8 | 3038–3174 |
| Fillister Head Slotted Machine Screws | 1-72 × 1/8 → 1/2-13 × 4 | 3175–3204 |
| Flat Head Slotted Machine Screws | 1-72 × 1/8 → 1/2-13 × 4 | 3205–3237 |
| Round Head Slotted Machine Screws | 1-72 × 3/16 → 1/2-13 × 4 | 3238–3267 |

The A-suffix socket head cap screw bins are a separate series from the plain ones and overlap them numerically: small sizes are in the A series, larger sizes in the plain series.
